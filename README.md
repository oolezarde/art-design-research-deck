# Art Design Research Deck

A Codex skill for evidence-led editorial presentations about art, design, publishing, exhibitions, visual culture, artist/designer research, and portfolios.

It treats a deck as an editorial sequence. Visual direction is derived from the research subject or supplied references, while typography, image handling, citations, native editability, rendering, and critique remain part of the same workflow.

## Install in Codex

Install the skill from this repository path:

```text
skills/art-design-research-deck
```

After installation, start a new Codex task and invoke it with `$art-design-research-deck`, or ask for an art/design research presentation in natural language.

## What it contains

- Two entry modes: reference-led and subject-led
- Research → evidence → narrative → visual system → slide rhythm workflow with revision loops
- Traceable image, claim, citation, and speaker-notes provenance
- Editorial typography and layout guidance
- Native PPTX editability and render-based critique requirements
- Explicit checks against generic corporate and AI-template aesthetics

The repository contains the installable skill under [`skills/art-design-research-deck`](skills/art-design-research-deck/).
