# Visual System & Editorial Layout — 视觉系统与编辑版式

## 参考提取的最小记录

| 层级 | 要记录什么 | 怎样避免误读 |
|---|---|---|
| 来源 | 文件/URL、页号、作品名、采集日期 | 参考 deck 的样式和艺术家本人的风格分开记 |
| 画布 | 宽高、比例、页序、跨页关系 | 记录测量单位；比例以实测为准 |
| 色彩 | 实际使用色、theme 色、角色、面积关系 | theme palette 里没用到的色留在记录里，不进 deck |
| 字体 | 中西文 family、字重、字号、段落/字距、替代字体 | theme 与 run 分开；从图像辨认的字体标为推测 |
| 元素 | type、x/y/w/h、旋转、crop、z-order、group/parent、原始页 | 同时保留原单位与归一化坐标；组内坐标需转换 |
| 页型 | 封面、目录、分析、图版、转折、比较、尾页及特殊页 | 分类是候选，保留原始页序和反例 |
| 素材 | 图像、背景、嵌入对象、layout/master 来源、ID | 作品图和装饰性内容图分开对待 |
| 关系 | 对齐、间距、尺度差、视线顺序、caption 绑定 | 先观察关系，再适配展示环境 |

PPTX 用原始结构与渲染交叉核对；PDF/图片可用于观察可见的遮挡和布局关系，但不足以恢复原始 PPTX 的 z-order、分组或可编辑结构。未取得原文件结构时将这些原始属性记为 unresolved；为复现画面提出的组织方式另记为重建方案，不冒充提取结果。提取结果使用 verified / inferred / unresolved，并为推断保留可见依据；仅标 inferred 不能弥补证据缺失。网站要区分界面导航和作品自身。书籍记录单双页、页边、书口与装订可见性。这些置信状态与设计决定的四类理由分开记录。

## 可迁移的参数约定

重要的结构转译记录四步：观察证据 → 结构机制 → 页面动作 → 解释边界；另标 Observed / Functional / Interpretive / User-defined 类别。Functional 或 User-defined 的决定可以把某条观察证据标为不适用，写明需求即可。观察边界、单位、累积、顺序、固定容器、容量变化与反馈，也判断配色、字体和留白是否直接承担编码、分组、层级或阅读节奏的结构作用。

例如有证据支持固定容器与内容增加时，可以保持比较框一致来展示容量差异；示意的厚度标为示意。研究框架被后续证据修正时，页面结构呈现这种反馈，结论回应开场的问题。放大图像或换字族是否构成结构转译，取决于它如何支持观察、比较或解释，不能仅凭视觉变化宣称转译成功；纯视觉入口不需要承担同等的分析任务。

为当前研究项目记录参数，palette 和模板都从项目里长出来：
- canvas：尺寸/比例、单位与展示用途。
- typography roles：display、section、analysis、caption、source、footnote、folio；每项有字体、fallback、字重、字号、行距、对齐。
- spatial rules：基线、外边距、栏/对齐线、图注与图像距离、阅读方向。
- image policies：contain/crop 的理由、全图/细节关系、比较尺度。
- case overrides：案例可调整项、例外原因、证据 ID。
- provenance：重要参数的 Observed / Functional / Interpretive / User-defined 理由；声称来自观察的决定对应到证据定位。

card、icon-kit、button、shadow 或 graphic motif 这类字段只在研究对象或参考确实需要时出现。参数用来维持读者可理解的层级，而不是强迫所有页面一致。

## 色卡与代表页

全稿应用前枚举界面色卡：主要底色、可选第二底色、正文色、注释色及必要的强调色，记录色值、用途、适用页角色与数量预算。作品原色单独管理，不受界面色卡限制。需要新增颜色时更新全局预算，让它成为系统的一部分。

先做色卡和约 3–5 张代表页，覆盖密集分析、真实作品、最长图注/项目名、裁切、来源页，以及计划使用的深色底；页数按任务调整。这是执行检查点，用户已授权时自行推进。收到"单调"的反馈时先诊断是层级、论证密度、节奏还是颜色的问题，调整最相关的变量。

类似出版研究可以从少量底色起步，数量按项目需要。某个案例曾采用暖纸色 #F2EEE5、墨蓝 #233F4D、石板灰 #5C6C73，作为项目记录保留；宋体/Baskerville 这类编辑选择是我们的选择，与研究对象自己的字体系统分开记。

## 字体是结构

中文、英文、韩文作品名及数字分别检查字形覆盖。用户指定的字体优先；缺字体时选择明确的替代并记录，重查换行与尺寸，让替换是一个有记录的决定。

以实际放映或阅读尺寸试排正文、图注和来源；字号从阅读距离推导，而不是继承第三方的 36/16/10pt。caption/source 保持可读，满页的问题先减冗词、调整结构或增加页数来解决；页数固定时回到叙事取舍。引文保留原文与必要翻译，译者/自译可追溯。

caption 紧邻对应证据，source 用短 ID 联到完整出处；同一页多个证据逐一对应。页码提供定位，标题和 footer 按页面角色决定是否出现。原作品中的文字是作品图的一部分，另写的分析文字保持可编辑。

## 版式生成

从阅读任务出发：完整作品观看、spread 顺序、局部证据、并置比较、注释分析、文字暂停或综合判断。先确定重点与观看尺度，再放文本和来源，让布局从任务里长出来。

对齐可以严格，页序可以不对称。比较页可以同尺度；实物比例未知时标"非同比例"。连续重复作为有意的观察序列时写下理由。每个 graphic gesture 承担注释、测量、导航或论证中的一种；空白本身是一个有效的状态。

## 原生 PPTX 的实现约定

使用宿主可用的标准 presentations/slides 工具构建和验证文件，读取其当前说明；仅在需要时选择底层原生写入库。把本 skill 的研究、布局、证据与节奏要求传入构建过程。首次调用时做代表性导出检查；实现方式不依赖第三方 script 或固定的本机路径。

内容与布局源文件分开；元素有稳定 ID 和来源映射。标题/分析/图注用真实文本框；图片用可替换的图片对象；基本框架、线条与注释用原生 shape。复杂图形需要栅格化时，记录对象级例外并保留源文件。

验收标准：能选中并修改文字、移动基本图形、替换图片，重开后渲染稳定。HTML 预览辅助判断，最终以实际 PPTX 渲染为准。原生"图片可移动"和图片内容可逐笔编辑是两回事，如实描述。
