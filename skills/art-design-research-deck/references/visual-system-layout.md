# Visual System & Editorial Layout — 视觉系统与编辑版式

## 参考提取的最小记录

| 层级 | 要记录什么 | 如何避免误读 |
|---|---|---|
| 来源 | 文件/URL、页号、作品名、采集日期 | 参考 deck 的样式不自动代表艺术家的风格 |
| 画布 | 宽高、比例、页序、跨页关系 | 记录测量单位；不要默认 16:9 |
| 色彩 | 实际使用色、theme 色、角色、面积关系 | theme palette 未使用色不自动进入 deck |
| 字体 | 中西文 family、字重、字号、段落/字距、替代字体 | theme 与 run 分开；图像辨认字体只作推测 |
| 元素 | type、x/y/w/h、旋转、crop、z-order、group/parent、原始页 | 同时保留原单位与归一化坐标；组内坐标需转换 |
| 页型 | 封面、目录、分析、图版、转折、比较、尾页及特殊页 | 分类是候选，保留原始页序和反例 |
| 素材 | 图像、背景、嵌入对象、layout/master 来源、ID | 作品图不能按“内容图”丢弃 |
| 关系 | 对齐、间距、尺度差、视线顺序、caption 绑定 | 观察关系后再适配展示环境 |

PPTX 用原始结构与渲染交叉核对；PDF/图片只能获得部分信息，不能推断出真实 z-order 或可编辑结构。网站要区分界面导航和作品自身。书籍记录单双页、页边、书口与装订可见性。提取结果标记 verified / inferred / unresolved 与证据位置；这是提取置信状态，区别于设计决定的四类理由。

## 可迁移的参数约定

重要的结构转译记录：观察证据 → 结构机制 → 页面动作 → 解释边界；另列 Observed / Functional / Interpretive / User-defined 类别。Functional 或 User-defined 决定可将观察证据标为不适用，写明需求，不编造作品先例。优先考察边界、单位、累积、顺序、固定容器、容量变化与反馈，而不止于配色、字体和留白。

例如有证据支持固定容器与内容增加时，可保持比较框一致，展示容量差异；示意厚度不得冒充实测。研究框架被后续证据修正时，页面结构应呈现反馈，结论回应开场问题，不再退回旧单向链。仅放大图像或换字族不足以证明分析页完成结构转译；纯视觉入口不必承担同等分析任务。

为当前研究项目记录参数，不随 skill 预置 palette 或模板：
- canvas：尺寸/比例、单位与展示用途。
- typography roles：display、section、analysis、caption、source、footnote、folio；每项有字体、fallback、字重、字号、行距、对齐。
- spatial rules：基线、外边距、栏/对齐线、图注与图像距离、阅读方向。
- image policies：contain/crop 的理由、全图/细节关系、比较尺度。
- case overrides：案例可调整项、例外原因、证据 ID。
- provenance：重要参数采用 Observed / Functional / Interpretive / User-defined 理由；只有声称来自观察的决定必须有对应证据定位。

不默认 card、icon-kit、button、shadow 或 graphic motif 字段。参数用于维持读者可理解的层级，而不强迫所有页面一致。

## 色卡与代表页

全稿应用前枚举界面色卡：主要底色、可选第二底色、正文色、注释色及必要强调色，记录色值、用途、适用页角色与数量预算。作品原色单独管理，不受界面色卡限制。新增色需更新全局预算，不逐页临时加色。

先做色卡和约 3–5 张代表页，覆盖密集分析、真实作品、最长图注/项目名、裁切、来源页，以及计划使用的深色底；页数按任务调整。这是执行检查点，用户已授权时不强制等待批准。收到“单调”先诊断层级、论证密度、节奏或颜色，优先调整最相关变量，避免同时更改过多因素。

类似出版研究可从少量底色起步，但两种不是通用上限。案例曾采用暖纸色 #F2EEE5、墨蓝 #233F4D、石板灰 #5C6C73；仅作项目记录，不默认复用。宋体/Baskerville 等编辑选择不能追认为研究对象自己的字体系统。

## 字体是结构

中文、英文、韩文作品名及数字分别检查字形覆盖。用户指定字体优先；缺字体时选择明确替代并记录，重查换行与尺寸，不能让系统静默代换。

以实际放映或阅读尺寸试排正文、图注和来源；不机械继承第三方的 36/16/10pt。caption/source 必须可读，不能靠降到极小字号解决满页。字号不足时先减冗词、调整结构或增加页数；页数固定则回到叙事取舍。引文保留原文与必要翻译，译者/自译标记可追溯。

caption 紧邻对应证据，source 用短 ID 联到完整出处；同一页多个证据逐一对应。页码提供定位，不强制每页放大标题或相同 footer。原作品中的文字仍是作品图的一部分，另写的分析文字保持可编辑。

## 版式生成

从阅读任务出发：完整作品观看、spread 顺序、局部证据、并置比较、注释分析、文字暂停或综合判断。先确定重点与观看尺度，再放文本和来源。不要按预制 slide type 先填槽。

对齐可以严格，页序可以不对称。比较页可同尺度；实物比例未知时标记“非同比例”。连续重复作为有意观察序列时保留理由。每个 graphic gesture 必须承担注释、测量、导航或论证，空白不触发装饰。

## 原生 PPTX 的实现约定

使用宿主可用的标准 presentations/slides 工具构建和验证文件，读取其当前说明；仅在需要时选择底层原生写入库。将本 skill 的研究、布局、证据与节奏要求传入构建过程，不套用通用视觉默认值。首次调用时做代表性导出检查，不绑定第三方 script 或固定本机路径。

内容与布局源文件分开；元素有稳定 ID 和来源映射。标题/分析/图注用真实文本框；图片用可替换图片对象，基本框架、线条与注释用原生 shape；不得把所有文字和图像合并成一张页面图片。复杂图形如须栅格化，记录对象级例外，保留源文件。

验收需能选中并修改文字、移动基本图形、替换图片，重开后渲染稳定。HTML 预览只能辅助，不能替代实际 PPTX 渲染。原生“图片可移动”不代表图片内容可逐笔编辑。
