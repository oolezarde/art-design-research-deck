# 设计原则

## 八项原则

1. **Design follows research.** 先弄清研究对象、问题、已知事实和手上的材料，视觉方向从这里长出来。当研究还不够支撑一个方向时，把缺口记下来继续查，而不是先做一个好看的封面再倒推论点。
2. **Style is derived, not selected.** 视觉方向从研究对象和参考里推导，同时允许可读性、编辑判断和用户的明确要求来决定具体做法。minimal、clean、premium 这类词是形容词，不是一个可以执行的概念；遇到它们时追问一句"对这个对象来说，它具体意味着什么"。Derived 不等于模仿：不是每个决定都需要先例，但每个重要决定都需要一个能说出口的理由。
3. **Editorial sequence.** 页与页的关系和单页本身同样重要：观看距离、信息密度、证据尺度、翻页动作与章节转折都在设计范围内。节奏可以不对称，只要不对称有它的阅读理由。
4. **Visual evidence before decoration.** 作品、spread、detail、装帧、展场、档案和原始图表优先上屏。每张图先回答"它让读者看见什么"，这个答案决定它的位置和尺寸。
5. **Empty space is valid.** 空白和纯文字页可以承担停顿、提问、对照和结论；完成度看论证是否充分，不看画面填了多少。留白省略的是装饰，不是分析。密集的案例保持密集，让读者看见它们之间的关系；需要提升的是分析密度和形式论证，而不是装饰密度。
6. **Typography is structural.** 标题、论述、caption、source、footnote、folio 各自承担一种阅读角色，从初始编排起就为它们留出位置和层级。
7. **Sources remain traceable.** 作品图、案例、引文、数据和重绘图各有可追溯的 ID 和出处；分析推断与作者陈述分开写，让读者知道哪句是观察、哪句是解释。
8. **Native editability matters.** PPTX 里的正文、标题、图注、基本形状和图片对象保持可编辑；复杂作品本身作为图像整体保留，不为了"可编辑"拆散作品，也不把截图包装成原生文件。

## 那些会自动冒出来的动作

下面这些动作禁止未经判断就默认套用。每当想这样做，先问它在这一页承担什么阅读任务。卡片、渐变、两栏或规则性重复可以在有具体依据时使用，记录其功能与适用范围；单件参考不足以启用整套预设。这种版式弹性不放宽真实作品、裁切完整性和来源可追溯的要求。

**想把内容放进卡片。** 先问边框在替谁做区分。多数时候证据之间的关系比容器更值得被看见，让对齐和间距承担分组，边框只留给真的需要隔离的东西。

**想用三个 icon 配三条要点。** 这个格式把不同重量的内容压成同一重量。先看这三条是否真的平行；如果一条是主张、一条是证据、一条是限定，就让它们的尺寸和位置说出这种差别。

**想加渐变、玻璃效果或有机 blob。** 问它在这页上指向什么。如果答案是"让页面不那么空"，回到第五条原则；如果它确实对应研究对象里的某种材料或结构，把那个对应关系写进推导记录。

**想在空处放一个形状。** 空处通常在等一张还没找到的图、一句还没写的分析，或者它本来就该是空的。先弄清是哪一种。

**想用 AI 生成的图代替作品图。** 作品图是证据，生成图不是。找不到作品图时，回到研究去找，或者调整论点让现有证据够用；只有用户明确要求时才生成辅助图，并且标明它的生成性质、与作品证据分开编号。

**想让每一页都用同一个两栏布局。** 一致的布局适合严格比较，不适合承载不同的阅读任务。先按页面角色决定读者这一页要做什么，再决定布局；同构的连续页面要能说出它们在比较什么。

**想让所有图片一样大、所有页面一样满。** 尺度和密度是叙事工具。作品应该在多远的距离被看、这一页是停顿还是推进，这些决定图片的尺寸和文字的量。让它们变化，并且让变化有理由。

**想裁掉作品里"不重要"的部分。** 作品的完整性是研究证据的一部分。需要 detail 时另做派生图，同页或邻页给出全图定位，让读者知道自己在看局部。

**想把 caption 和 source 留到最后再补。** 它们是版式的一部分，从初始结构起就占位。最后才塞进去的小字几乎总是破坏阅读，并且暴露出"来源是事后想起的"。

**想把 minimal、clean、premium 当成方向。** 回到第二条原则：把形容词翻译成这个对象的具体特征，然后从特征推导。

## 统一什么、放开什么

统一的是阅读逻辑：证据编号、字体角色、标点、图注语法、来源索引和测量单位。放开的是案例的呈现：主图尺度、文本量、构图和页数可以随案例变化；背景与强调色在全局色卡和角色预算内变化，不为每个案例单独配色。共同的阅读逻辑不等于共同的装饰 motif。

真实作品里的 logo、特殊字距、噪点、粗糙印刷或高密度是研究证据，按企业品牌规范去"清理"它们会抹掉信息。区分"原作品的属性"和"我们添加的呈现语言"，观测到的作品特色是观察，不是我们的设计。

## 推导记录

影响整体方向的重要决定记录它的来源类别，可以并列使用：

| 类别 | 依据 | 记录方式 |
|---|---|---|
| Observed | 研究对象或 reference 中可核对的特征 | 指向作品、页号或 evidence ID，写明适用范围与反例 |
| Functional | 可读性、展示环境、信息层级或技术限制 | 写明阅读需求及验证方式，不需要作品先例 |
| Interpretive | 对研究内容的编辑性转译 | 说明依据和转译关系，标为我们的解释 |
| User-defined | 用户明确的审美或使用要求 | 记录要求及其对系统的影响 |

caption 放在左下角可以是 Functional 的决定，不需要为它找一本书当先例。Observed 的旁注关系可以启发 Interpretive 的分析层级，但单件作品概括不了整个生涯。记录量按任务规模合并，不要求逐个坐标写理由。

下面是虚构的记录示例，仅说明写法，不提供可直接套用的证据、比例或版式：

> 假设已核对的两张内页显示：同一编码单位随页序累积。Observed：记录具体图像 ID、页号和可见变化。Interpretive：在讨论累积的比较页保留统一单位，让差异通过数量与顺序显现；这是我们的分析呈现，不声称是作者的工作方法。Functional：图注紧邻对应证据，按显示尺寸检查可读性。适用范围：这组比较页；其他分析页按自己的证据与阅读任务设计。

按决定类别记录必要依据：Observed 需要证据定位，Functional 需要可说明的功能理由，Interpretive 需要研究依据与转译关系，User-defined 必须来自用户的明确要求。模型自己的审美偏好先记为待验证的编辑提案，不冒充用户要求，也不靠改标签补足缺失证据。无需为了满足记录格式而给纯功能性决定寻找作品先例。

## 怎样知道方向已经成立

把研究对象的名字换掉，这份 deck 是否几乎仍能原样使用？如果能，视觉推导还没有真正发生。反过来，读者是否能沿着证据看出这个系统是从研究里形成的？这两个问题在开始 Build 前和交付前各问一次。
