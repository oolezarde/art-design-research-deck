# QA 与设计 critique

## 两条验收线

技术上可打开和编辑质量是两条独立的验收线，分别检查。自动程序提供的是风险线索；空白面积、图形数量、布局多样性分数或 style fidelity 百分比说明不了设计是否成立，成立与否要看渲染出来的页面。

流程：实际交付的 PPTX → 全页渲染 → contact sheet → 逐页放大检查。记录渲染器、字体/替代字体和版本；说明是否在目标 PowerPoint/Keynote 环境验证。HTML 或源代码通过只说明源文件没问题，PPTX 本身另行验证。

## 技术与证据检查

分开报告三个状态：文件结构检查、重新读取实际 PPTX 后的渲染检查、目标应用实测。前一项通过是后一项的前提，不是替代；说明字体是否嵌入、是否发生替换，单一渲染器的成功记为该渲染器的结果。

代表页额外检查：裁切在重读后是否保留、中文孤行、最长名称/图注是否压图、白色书页边界是否可辨、时间线终点是否与数据一致。按实际内容选择检查项。

- overflow / overlap / clipping：检查真实字形、边界、图注、页脚、分组/旋转对象和图片遮挡；有意叠放写明理由。
- font substitution：中西文/韩文/数字覆盖、缺字、fallback、换行变化和字重。
- image resolution / aspect ratio：有效分辨率、像素化、拉伸、spread 顺序、裁切和细节对应。
- source traceability：每项作品、案例、引文、数字和重绘图都能通过 ID 找到具体出处。
- speaker notes provenance：备注随文件保存，页面、证据和论点 ID 对应，完整来源可访问；备注不受支持时核查随稿来源表或附录。
- caption consistency：语法、作品名/年份/credit、位置关系与编号一致。
- typography hierarchy：论点、分析、作品标题、caption、source、footnote、folio 的职能可辨，在实际展示尺寸下可读。
- native editability：文本、基本 shape、图片对象能独立选中修改；抽查每种元素类型和最复杂的页；栅格化例外明确。
- 输出完整性：页数与 storyboard 一致，内容完整，素材已嵌入，预览页数匹配，占位项已披露。

几何检测区分 intentional overlap 与错误：矩形相交不一定是可见冲突，文本框在界内也可能字形溢出，所以最终看渲染。来源/事实错误、丢字、核心作品被误裁、不可读与虚假的可编辑性属于交付阻断项。

## 全 deck 设计 critique

独立阅读稿关掉备注再读分析页：能否读出"看到了什么—怎样解释—意味着什么"？漂亮的结论或不溢出的文字只是必要条件。按页面角色修复，开场和暂停页保持它们自己的功能。

检查关键页的尺寸、顺序、边界和位置是否承担比较或解释的任务；结论是否回答开场的问题；修订后的模型是否在后页保持一致。这些跨页依赖与已奏效的页面一起核对，布局变化时保护有效的比较关系。

全稿总览与关键单页结合检查：色值是否属于界面色卡、第二底色是否承担明确作用；作品原色不参与界面色值的判定。评价看阅读效果，而不是布局数量或连续页面是否同构。

用 contact sheet 和连续播放一起问：
- 连续多页相同构图时，重复是否支持比较或阅读顺序？
- 图片尺寸和观看距离是否有变化？变化是否有理由？
- 页密度和节奏是否随论证起伏？章节之间除了标题还有什么在变？
- 每个 graphic gesture、gradient、装饰线或 blob 是否有概念理由？
- 是否出现了 generic AI-presentation 的样子：随处卡片、三图标三要点、统一大数字？
- icon、shape 或 template motif 是否在替代应该由证据承担的工作？
- 该安静的页是否安静？密集的案例是否仍能看见关系？
- 案例之间的差异是否被保留？作品色彩和裁切是否忠于原作？
- 图注与来源是否从初始结构就在位置上？
- 把研究对象的名字换掉，这份 deck 是否几乎仍能原样使用？如果能，重新检视视觉推导的依据。
- 读者能否沿着证据看出这个系统是从研究中形成的？
- 重要决定的 Observed / Functional / Interpretive / User-defined 理由是否诚实？功能性安排和作品特征是否分开，编辑转译和作者意图是否分开？

这些是判断工具，不是每种构图必须出现一次的清单。刻意稳定的序列可以成立，说明稳定在阅读上的作用即可。

## 问题记录与修订

记录 page/element ID → 观察到的问题 → 影响 → 严重程度 → 拟议修复 → 复核结果。
技术问题优先修复源文件；证据不足回到研究；节奏失衡回到页序。删除无用装饰往往比补装饰有效；极简同样是一种需要理由的选择。

改后重渲染受影响的页，核查相邻页与全 deck 缩略图；涉及全局字体、画布或模板参数时重渲染全稿。已知的阻断问题持续修复到解决。环境限制导致无法验证时，列明未验证项，报告只写实际验证过的范围。

对照修改前后的保护清单，检查有效页面关系、claim/image/source ID、备注及页映射是否完整；复核画面、备注与台账中的设计说明，尤其是改色或改结构后需要更新的旧描述。自动化可以提示色卡外色值、缺失 ID 或过期映射，设计判断仍然由人做；没有执行的自动检查在报告里写为未执行。

交付说明包含：验证范围、来源台账、编辑性例外、已知限制、重大修订。testcase 的状态如实记录。
