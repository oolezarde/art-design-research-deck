# 图像与来源处理

## 先找到值得展示的证据

从艺术家/工作室、出版方、展览机构、馆藏、项目档案优先定位作品。二手页面可以提供线索，顺着它回溯原始出处；回溯不到时记录二手性。用户提供的图像同样记录文件身份与已知来源，授权和作者身份以确认为准。

书籍研究优先 cover、完整 spread、页序、detail、binding/书脊/书口、材料与实物观看图；展览研究保留安装环境与尺度。每张图先回答"展示它能证明什么"，答案决定它是否进入 deck 以及放在哪里。好看但说明不了什么的图留在证据板上备用。

## 可追溯台账

快速小稿用一张 image → source → claim 对照表，记录必要 credit、未知项和图像改动。正式研究稿使用以下字段，可以合并保存：
- evidence ID、作者/设计者、作品/出版物名、年份（未知就写未知）。
- 来源页面 URL/书目与页号；直接媒体 URL 可另列，来源页仍然保留。
- 本地文件名、像素尺寸、获取日期、摄影/机构 credit、已知权利或使用条件。
- 证据类型、支持的 claim ID、计划/实际出现的页号。
- 原图/派生图关系、crop/旋转/调色等操作和理由、是否为细节。
- 状态：verified、secondary、user-provided、unresolved；记录不确定点。

claims 表记录论点、支持/反证、source/evidence ID、事实/引文/分析类别。引文记录准确文本、定位和翻译；数据记录单位、时间范围与方法。自己绘制的分析图标为"分析性重绘"并保留原始依据，读者由此知道它不是作者原图。

画面上用短 caption：作者／作品／年份／图像角色；credit 与短 source ID 用统一语法。完整来源放在索引或备注里，图上的 ID 与索引双向对应。公开可访问不等于开放许可，权利未知时如实写"未知"。

## PPTX 讲者备注中的出处

来源按三层组织：画面保留紧邻作品的项目名、必要署名/年份、短 source/image ID，以及直接影响主张理解的限定语；speaker notes 保存完整 URL、claim 依据、图像派生记录和详细方法；参考页或随稿文档汇集来源索引、权利说明与研究范围。独立阅读稿的核心解释留在画面上，备注做补充。

页脚里"本研究分析""详见备注"这类声明只在它真的传递信息时出现。用户要求清理页脚时，识别具体的文本对象，保留图注、ID、页码及全部备注，除非另有指示；必要的限定语在画面上仍有位置。核查被移除的信息在适当层级仍能找到。

重建或重排页面时对照原 ID 与备注，让来源随页面迁移。改色、裁图、改框架后，同步检查画面、备注、Design DNA 和来源表中有关颜色/结构/页号的说明，把过期的记录一并更新。

工具支持时，把每页完整出处随 PPTX 保存到 speaker notes：页面用简短 source ID，备注关联 Sources（完整书目/URL/页号）、Images（evidence ID、文件身份、credit、裁切）和 Claims（claim ID、论点、事实或推断）。只写实际核对过的信息，保留正常讲稿；路径用相对或可分享的形式。

导出后抽查备注中的 ID、URL 与页面是否一致。备注会随文件分享出去，密钥、私密路径和不该外传的信息放在别处。导出器保存不了备注时，用随稿来源表或附录保存完整对应关系，并披露这个限制。用户明确指定来源格式时遵从；画面上必要的 credit 仍然保留。

## 图像完整性

默认等比 contain。保留 spread 的书脊、页边和左右顺序；论证需要 detail 时另建派生图并说明裁切范围，同页或邻页给出全图定位。核心内容在适配画布时优先保护。

先看实际图像再裁切；反光、色偏和拍摄透视会影响对材料和颜色的判断。作品本身保持原色和原有标识，palette 统一只作用于界面元素。技术性校正保留原图与操作记录。

按有效像素检查清晰度：裁切后的有效宽高要够支撑最终显示尺寸。低分辨率时找更高质量的源、缩小展示或明确说明局限。屏幕观看与印刷需求分别判断。

## 缺图处理

记录缺口 → 搜索合法可获取的版本或其他可验证的证据 → 调整论点、尺度或页序。仍然不足时说明缺少什么，让缺口本身成为可见的信息；icon、stock photo 或 AI 装饰填不上证据的空位。草稿可以用明确的缺证据注记占位，交付前处理或披露。

用户明确要求时可以生成辅助图，与原作证据分开标注、分开编号，用于说明而不是用于支持关于真实作品的事实。调用外部模型前说明服务用途和数据去向；作品和私人参考的上传以用户确认为准。
