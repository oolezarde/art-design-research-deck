# 图像与来源处理

## 先找到值得展示的证据

从艺术家/工作室、出版方、展览机构、馆藏、项目档案优先定位作品。二手页面可提供线索，回溯原始出处；找不到时记录二手性。用户图像同样记录文件身份与已知来源，不擅自认定授权或作者。

书籍研究优先 cover、完整 spread、页序、detail、binding/书脊/书口、材料与实物观看图；展览研究保留安装环境与尺度。每张图先回答“展示它能证明什么”，再决定是否入 deck。没有用处的图不因好看而加入。

## 可追溯台账

快速小稿可用一张 image → source → claim 对照表，记录必要 credit、未知项和图像改动；无需另建多个台账。正式研究稿使用以下字段，可合并保存：
- evidence ID、作者/设计者、作品/出版物名、年份（未知就写未知）。
- 来源页面 URL/书目与页号；直接媒体 URL 可另列，但不代替来源页。
- 本地文件名、像素尺寸、获取日期、摄影/机构 credit、已知权利或使用条件。
- 证据类型、支持的 claim ID、计划/实际出现的页号。
- 原图/派生图关系、crop/旋转/调色等操作和理由、是否为细节。
- 状态：verified、secondary、user-provided、unresolved；记录不确定点。

claims 表记录论点、支持/反证、source/evidence ID、事实/引文/分析类别。引文记录准确文本、定位和翻译；数据记录单位、时间范围与方法。自己绘制的分析图标为“分析性重绘”，保留原始依据；不能冒充作者原图。

显示短 caption：作者／作品／年份／图像角色；credit 与短 source ID 统一语法。完整来源放可用的索引或备注，图上 ID 与索引双向对应。公开可访问不等于开放许可，未知权利如实记载；不得猜许可证。

## PPTX 讲者备注中的出处

在工具支持时，把每页完整出处随 PPTX 保存到 speaker notes。页面用简短 source ID，备注关联 Sources（完整书目/URL/页号）、Images（evidence ID、文件身份、credit、裁切）和 Claims（claim ID、论点、事实或推断）。只写实际已核对的信息，保留正常讲稿；不要只存本机绝对路径。

导出后抽查备注中的 ID、URL 与页面一致。备注并非隐私区；不要放密钥、私密路径或不应共享的信息。若导出器不能保存备注，用随稿来源表或附录保存完整对应关系，并披露限制。用户明确指定来源格式时遵从，备注不能代替必要的可见 credit。

## 图像完整性

默认等比 contain，不拉伸。保留 spread 的书脊、页边和左右顺序；若论证需要 detail，另建派生图并说明裁切范围，同页或邻页给全图定位。核心内容不可因适配画布随便切掉。

先看实际图像再裁切，不依赖文件名判断；反光、色偏和拍摄透视会影响材料/颜色判断。作品本身不要为了 palette 统一而重新着色、套滤镜或抹除标识。技术校正须保留原图与操作记录。

按有效像素而非文件体积检查清晰度：裁切后的有效宽高应足以支撑最终显示尺寸；放大不能增加细节证据。低分辨率时找更高质量源、缩小展示或明确局限。屏幕观看与印刷需求分别判断，不把 300dpi 当所有场景的统一门槛。

## 缺图处理

记录缺口 → 搜索合法可获取的版本/其他可验证证据 → 调整论点、尺度或页序。仍不足时说明缺少什么；不要默认补 icon、stock photo 或 AI 装饰。草稿可用明确的缺证据注记，但不设计成伪作品，交付前处理或披露。

只有用户明确要求时才可生成辅助图；与原作证据分开标注、分开编号，不用于支持关于真实作品的事实。任何外部模型调用需明确服务用途和数据去向，不能因为已安装 SDK 就自动上传作品或私人参考。
